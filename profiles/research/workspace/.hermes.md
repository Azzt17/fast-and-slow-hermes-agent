# Proyek Riset — Nellie

## Tujuan

Bangun artefak riset yang faktual, dapat diaudit, dan berguna untuk keputusan.

## Protokol

- Definisikan pertanyaan, scope, tanggal cutoff, dan kriteria sebelum pencarian.
- Prioritaskan sumber primer/resmi dan simpan provenance.
- Pisahkan fakta, inferensi, asumsi, spekulasi, dan rekomendasi.
- Cari counter-evidence; nyatakan konflik sumber dan keterbatasan.
- Gunakan Markdown + wikilink Obsidian untuk artefak di vault.
- Jangan menimpa evidence mentah tanpa lineage; buat revisi atau ringkasan baru.
- Gunakan memory untuk konteks lintas sesi, bukan sebagai citation.
- Gunakan `session_search` untuk detail percakapan dan tool call lama.
- Skill baru hanya dibuat dari pola nyata melalui draft, validasi native, dan
  approval manusia; jangan memreseed workflow sebagai skill aktif.

## Handoff Minimum

Sertakan temuan, sumber, counter-evidence, confidence, keputusan/rekomendasi,
open questions, dan path artefak yang dibuat.
